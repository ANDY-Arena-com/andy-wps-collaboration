## A. Zwei getrennte technische Schichten
1. Native WP/Aculia/Elementor/WpSection: Content Manager und selektive Transformation von Demo-Strukturen. Ursprüngliche Aculia-Home bleibt erhalten.
2. Isolierter RGB-Pilot: derzeit sichtbare Arbeitsansicht der Testinstallation, liefert versionierte HTML/CSS/JS-Dateien über WP aus, **keine** migrierte native Beitrags-/Taxonomiearchitektur. Umschaltbar. Kein Theme-Fork. Die separate Cockpit-Navigation bündelt bestehende Funktionen.
Die spätere native Migration ist offen. Die Pilot-Abnahme ist keine Theme-Kompatibilitäts- oder Publikationsfreigabe.

## D. RGB-Pilot intern (tatsächlicher Code 0.5.3)
- Zugriff auf Cockpit/Import/Privatvorschau nur Administratoren (manage_options) auf exakt erlaubter Testinstanz. Admin-POST mit Nonce, expliziter Bestätigung und Lock. Content ZIP muss exakt 48 Dateien des eingebauten hashes.json enthalten; SHA-256 pro Datei vor und nach Speicherung. ZIP max 4 MB, Einzeldatei max 1 MB, unkomprimierte Summe max 4 MB; keine unbekannten Einträge/Traversal. Das ist ein fest gepinntes, vertrauenswürdiges Demo-Paket mit HTML/JS, **kein** allgemeiner ausführbarer Upload-Importer. Native Datenpakete weiterhin ohne beliebigen ausführbaren Code.
- Options: andy_rgb_pilot_ready_v050, andy_rgb_pilot_lock_v050, andy_rgb_v050_ + sha256(Dateipfad) für Base64-Inhalte, andy_rgb_standard_v051. Optionen nicht autoloaded bei Speicherung. UI 0.5.2/0.5.3 transformiert ausgeliefertes CSS und Header, keine Änderung der gespeicherten 48 Dateien. Versionsanzeige Content 0.5.0 / UI 0.5.3.
- Private Vorschau admin-post.php?action=andy_rgb_view&asset=…; Standardansicht Root und ?andy_rgb_asset=…; interne Verweise werden auf passende Routen umgeschrieben. Normaler WP-Admin/übrige WP-Routen bleiben unberührt. Keine Änderung an show_on_front, Beiträgen, Kategorien, Elementor oder Theme.
- Standardmodi off (Werkseinstellung/Aculia), admin (angemeldete Admins), staging (alle Besucher der erlaubten Testdomain). Explizite Auswahl, standardmäßig privat empfohlen; tatsächlich gewählter Modus nicht unabhängig bekannt. Testdomain/Host prüfen; bei fehlendem Paket/ungültigem Modus fail closed. Seiten-/CDN-Cache vor Umschaltung und Rückweg leeren/deaktivieren. noindex/no-store, Referrer-Policy, CSP same-origin frames und sandbox für eingebettete Module; noindex ist keine Zugriffssperre. Externe Player nicht einfach per URL in diesem CSP-Modell nachrüsten.
- Rückweg: Standardmodus off; Aculia unverändert. Pilot-Reset löscht nur eigene Optionen und gespeicherte Dateiblobs, nicht native Website; Reset ist kein notwendiger Schritt bei Updates. Keine Behauptung vollständiger Transaktionssicherheit.
- 0.5.0 Content: 24 Seiten plus 4 Originalmodule, 48 Dateien gesamt. Academy L01 Setup, L02 Go-Schlag, L03 Schach-Go und Research Fall001 als unveränderte HTML-Module im Paket. Research-Grafik 268 Entscheidungen, 247 ausgeführt, 21 nicht ausgeführt; Ausführung ≠ Qualität. Fünf Perspectives und Making of. Replay-Teaser sind noch kein vollständig integrierter Arena-Player.

## E. Bedienung / Pakettypen
Plugin-ZIP ausschließlich über Plugins → Plugin hinzufügen → Plugin hochladen; bestehendes Plugin aktualisieren, nicht als Content importieren. Cockpit → RGB Pilot erwartet ausschließlich das gepinnte Content 0.5.0; altes Paket bleibt gültig. Bei 0.5.1–0.5.3 kein erneuter Content-Upload. „Falsche Dateianzahl“ war im Nutzer-Test sichtbar; Verwechslung mit Plugin-ZIP war plausible Diagnose, nicht nachgewiesene Ursache. 0.5.3 enthält präzisere Fehlermeldung mit erwartetem Paket. Erst Diagnose, keine Löschung.
Verbindliche Dateinamen ab 17.11: Typ → Funktion → Version. ANDY-WP-PLUGIN-, ANDY-WP-CONTENT-, ANDY-WP-DESIGN-, ANDY-WP-MODULE-, ANDY-HTML-DEMO-, ANDY-REPLAY-, ANDY-QA-, ANDY-BACKUP-, ANDY-DOC-. Frühere Artefakte behalten tatsächliche Namen im Register; nicht stillschweigend umbenennen. Pakettyp/Version vor Verarbeitung ausweisen; allgemeine automatisierte Typklassifizierung noch offen. Separate Plugin-/Content-/Designpakete und Offline-Demos. Native Workflow weiterhin Dry Run → Konfliktprüfung → explizite Freigabe → Backup → Apply → Browser-Abnahme → selektiver Rollback. Demo-Cleanup bleibt bis Replacement Gate und Abhängigkeitsprüfung gesperrt.
